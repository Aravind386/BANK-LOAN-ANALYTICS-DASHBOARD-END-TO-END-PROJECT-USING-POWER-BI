
# 🏦 Bank Loan Analytics Dashboard using Power BI

### 📊 Loan Performance | Risk Analysis | Repayment Insights

An interactive Bank Loan Analytics Dashboard developed to analyse loan applications, funded amounts, repayments, interest rates, and borrower debt-to-income (DTI) ratios. The dashboard provides insights into loan performance, good and bad loans, loan purposes, employment length, home ownership, and application trends.

---

## 📌 Project Overview

The Bank Loan Analytics Dashboard helps analyse lending activities and understand the overall performance of a loan portfolio.

Using interactive dashboards, KPI cards, charts, and filters, the project provides a consolidated view of loan applications, funded amounts, amounts received, interest rates, and borrower DTI ratios.

The dashboard includes Summary and Overview pages to help users explore loan performance, identify patterns, and support data-driven lending decisions.

---

## 🎯 Project Objectives

- Analyse total loan applications and funded amounts.
- Track total amounts received from loan repayments.
- Monitor average interest rates and borrower DTI ratios.
- Compare good loans and bad loans.
- Analyse loan applications by purpose and loan term.
- Understand loan trends across months and states.
- Evaluate loan status based on funded amounts and repayments.
- Build an interactive dashboard for loan portfolio reporting.

## 🔍 Key Insights & Conclusions

- **Total loan applications:** The dashboard reports 38,576 applications.
- **Funded amount:** Approximately ₹435.8M was funded.
- **Amount received:** Approximately ₹473.1M was received.
- **Good loans:** Good loans account for 86.18% of applications, with 33,243 applications and a funded amount of ₹370.2M.
- **Bad loans:** Bad loans account for 13.82% of applications, with 5,333 applications and a funded amount of ₹65.5M.
- **Loan purpose:** Debt consolidation is the largest loan-purpose category shown, with approximately 18.2K applications.
- **Loan term:** The dashboard shows approximately 28K applications for 36-month loans and 10K for 60-month loans.
- **Home ownership:** Rent and mortgage are the two largest home-ownership categories shown in the dashboard.
- **Loan status:** Fully Paid, Current, and Charged Off loans are compared using applications, funded amounts, amounts received, interest rates, and DTI ratios.

*These insights reflect the figures displayed in the supplied screenshots. Confirm metric definitions, currency units, and loan classification rules against the source data. The amount received can exceed the funded amount because repayments may include interest and other applicable charges; this comparison alone does not establish profitability.*
